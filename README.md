# MusicRent

## Предметна область

Система обліку та оренди музичних інструментів.

## Основні сутності

- Instrument — музичний інструмент.
- InstrumentCopy — конкретний примірник інструмента.
- Customer — клієнт.
- Rental — оренда інструмента.
- Reservation — бронювання інструмента.

## Призначення застосунку

Застосунок призначений для обліку музичних інструментів, клієнтів, оренд і бронювань.
